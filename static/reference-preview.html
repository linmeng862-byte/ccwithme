帮我写一个Python函数，斐波那契数列，要有类型注解
思考过程 ▾
斐波那契数列有几种实现方式……递归的话简洁但有重复计算问题，O(2^n)；迭代的话O(n)时间O(1)空间；还有用lru_cache的记忆化递归。

她要类型注解，用 int -> int 就好，参数n是非负整数，返回第n项。

做迭代版本，最实用，再加一个生成器版本作为bonus，挺有用的。

两种实现，各有用处。

python
def fibonacci(n: int) -> int: """返回第 n 个斐波那契数（0-indexed）。""" if n < 0: raise ValueError("n 必须是非负整数") if n <= 1: return n a, b = 0, 1 for _ in range(n - 1): a, b = b, a + b return b from typing import Generator def fibonacci_gen(limit: int) -> Generator[int, None, None]: """生成前 limit 个斐波那契数。""" a, b = 0, 1 for _ in range(limit): yield a a, b = b, a + b

第一个是迭代版，O(n) 时间，O(1) 空间，直接用 fibonacci(10) 取单个值。

第二个是生成器，需要一批数的时候用 list(fibonacci_gen(10))，不用重复计算。
